    关于

    数据备份提醒

    本应用数据保存在浏览器 localStorage 中，可能被浏览器清理或清除上网数据时删除。建议定期点击「库存」页右上角 ⋮ →「导出备份」，在更换手机或清理数据前用「导入备份」恢复。

    离线与安装

    通过 HTTPS 托管后，可用浏览器「添加到主屏幕」安装，断网也能打开使用。若直接以 file:// 打开本页面，核心功能可用，但无法安装到主屏幕、无法离线。

    桌面安装引导（Windows）

    Chrome：打开线上网址 → 地址栏右侧「安装」图标（显示器+下载箭头）→ 点「安装」；或在右上角 ⋮ →「安装药品库存管理…」。

    Edge：打开线上网址 → 地址栏右侧「应用可用」图标（＋）→「安装」；或在右上角 ⋯ →「应用」→「将此站点安装为应用」。

    安装后可从开始菜单/桌面快捷方式打开，窗口 ≥768px 时自动切换为宽屏多列布局。

    条码扫码说明

    扫码需在 HTTPS 或 localhost 环境使用（浏览器安全限制），首次使用会请求摄像头权限；优先使用浏览器原生扫码（BarcodeDetector），不支持时自动联网加载备用扫码库（html5-qrcode）。扫码画面仅本地处理，不联网、不查外部药品库。

    微信浏览器限制

    微信内置浏览器不支持 PWA 安装与离线，且 OCR 联网加载可能受限。建议点击右上角「···」→「在浏览器打开」，使用系统浏览器。

    OCR 说明

    识别引擎（Tesseract.js + 中文语言包）在首次使用「拍照/相册识别」时联网下载；识别结果需人工确认后才扣减库存。手写单据识别率不保证，可用手动登记代替。
