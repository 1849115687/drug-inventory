# 药品库存管理（PWA）

面向药店/零售店的**纯前端、可离线**药品销售与库存管理小程序：零后端、数据存浏览器 localStorage，支持手动登记销售、拍照/相册识别销售单自动扣减库存，可添加到手机主屏幕离线使用。

> 配套文档：`docs/requirements.md`（需求）、`docs/design.md`（设计）、`docs/test.md`（测试）

## 功能一览

| 功能 | 说明 |
|---|---|
| 库存台账 | 添加/编辑/删除药品（名称、**规格可选**、**单位输入框+常用建议【盒/瓶/支】可自定义**、库存量、预警阈值，默认阈值 5）；库存 ≤ 阈值红色高亮，负库存显示「欠 N」 |
| 条码扫码 | 药品可设置**条码**（一药一码）；**添加药品表单**扫码自动填入条码（码已收录时提示对应药品）；**登记销售页「📷 扫码选药」**扫码直接命中并选中库存中该条码药品（过期药品阻止；未收录提示先添加）；浏览器原生 BarcodeDetector 优先、html5-qrcode CDN 懒加载降级，**APK 内走 Capacitor 原生扫码插件（系统摄像头）**，纯本地匹配不联网 |
| 价格管理 | 药品可设置进价/卖出价（元，两位小数，可留空）；库存列表显示卖出价（无价格显示「—」） |
| 有效期管理 | 药品可设置「有效期至」（日期，可空）；列表显示有效期，**临期（≤90 天）橙色标记、已过期红色标记**；**过期药品在销售（手动下拉不可选 + OCR 确认列表阻止 + 扫码命中阻止）时提示并阻止** |
| 登记销售 | 手动选择**药品 + 耗材混选**（可搜索，每项标注类型 + 库存 + 卖价；过期药品不可选）+ 数量 → 自动扣减库存/存量并记入销售记录（标注药品/耗材类型）；选后自动带出当前卖价（可修改），成功提示含金额；库存不足不阻止，可扣为负数并提示 |
| OCR 识别 | 「拍照/相册识别」销售单 → 引擎懒加载（Tesseract.js + 中文语言包，显示进度）→ 可编辑确认列表（**候选同时含药品与耗材**，过期药品标记并阻止）→ **「确认扣减」才是唯一写入开关**（扣减时按条目当前卖价记录售价快照） |
| 医疗耗材 | 「医疗」Tab「耗材」子视图：独立管理耗材（名称、**单位输入框+常用建议【片/根/卷/瓶/袋/包/支/盒/个】可自定义**、初始存量/阈值/进价/卖出价），列表显示存量与卖价，低存量红色高亮、「欠 N」；「进货/调整存量」（新存量或增加量）；删除二次确认（历史记录保留） |
| 医疗操作 | 「医疗」Tab「医疗操作」子视图：登记操作（类型可自定义，常用类型建议；勾选本次使用耗材与数量，可加多行）+ 备注 → **「确认记录」**后批量扣减耗材存量并写入操作记录（只增不改不删）；历史倒序可按类型筛选；耗材扣减允许负数 |
| 销售记录 | 按时间倒序，含单价与金额小计与**类型标签（药品/耗材）**，可按名称/来源（手动/OCR）筛选；只增不改不删；删除条目后历史记录仍保留 |
| 利润统计 | 「统计」Tab「销售统计」：总销售额/总成本/总毛利/毛利率汇总（**含药品与耗材售卖**）；按日期（日/月/自定义区间）与按条目（药品+耗材，标注类型，可排序）两种视图 |
| 耗材使用统计 | 「统计」Tab「耗材使用」：汇总总使用量 + 按日期（日/月/自定义）+ 按耗材（可排序）；使用量 = Σ 操作明细数量，口径注明 |
| 备份 | 导出 JSON（格式版本 **v4**，含药品/耗材/销售/操作/设置/**条码**）/ 导入恢复（**兼容 v1/v2/v3/v4 备份**，校验版本，二次确认后整体覆盖） |

## 本地运行（推荐）

电脑需要安装 **Node.js**（≥18；本机若已装则跳过）：

```bash
cd drug-inventory-app
node serve.js
```

启动后终端会打印访问地址（默认端口 8000，可用 `node serve.js 8080` 修改端口）：

- **本机访问**：`http://localhost:8000`
- **手机访问**：手机与电脑连接**同一 Wi-Fi**，用手机浏览器打开终端打印的 `http://192.168.x.x:8000`

> ⚠️ 局域网 IP 访问时核心功能全部可用，但**无法「添加到主屏幕 / 离线使用」**（Service Worker 仅 HTTPS 或 localhost 生效）。需要完整 PWA 请使用 HTTPS 托管（见下）。

> 没有 Node.js 时可用 Python 替代：`python -m http.server 8000`（本机未安装 Python 则不可用）。

## 两种使用方式

1. **直接打开文件（file://）**：双击 `index.html` 即可使用全部核心功能（添加药品、登记销售、记录、备份）。限制：**无法安装到主屏幕、无法离线**（Service Worker 仅 HTTPS/localhost 生效）；OCR 联网下载引擎可用。
2. **HTTPS 托管（完整 PWA）**：部署到任意 HTTPS 静态站（GitHub Pages / Netlify / 云厂商对象存储等），用浏览器打开后选择「添加到主屏幕」，断网也能打开使用。

### 部署示例（GitHub Pages）

把 `drug-inventory-app/` 下所有文件推送到仓库，在仓库 Settings → Pages 开启即可；或直接用 Netlify Drop 拖拽上传整个文件夹。

## 数据备份（重要）

- 数据保存在**浏览器 localStorage**，可能被浏览器清理（清除上网数据/存储空间不足等），**建议定期备份**：
  库存页右上角 **⋮ → 导出备份** 下载 JSON 文件；
  换手机/清理数据前，**⋮ → 导入备份** 恢复（导入为整体覆盖，二次确认后生效）。
- 导入**兼容 v1/v2/v3/v4 备份**：v1（无价格）/v2（含价格）/v3（耗材/操作/有效期）备份导入后，缺失字段自动补空（价格/有效期/条码 → null，耗材与医疗操作 → []），不影响使用；新导出的备份为格式版本 **v4**（含药品/耗材/销售/操作/设置/条码）。
- 卸载浏览器或更换设备不会自动迁移数据，请务必先导出。

## 价格与统计

- **价格**：在「库存」页添加/编辑药品、在「医疗」页添加/编辑耗材时可设置**进价**与**卖出价**（单位：元，最多两位小数，均可留空）。库存/耗材列表显示卖出价，未设置的显示「—」；进价在编辑弹层可见。
- **登记销售**：选中药品/耗材后自动带出该条目**当前卖出价**（可修改）；销售记录保存**售价快照**，之后改价不影响历史记录的销售额。
- **统计**（底部「统计」Tab）：
  - **销售统计**：汇总卡片（总销售额、总成本、总毛利、毛利率，销售额为 0 时毛利率显示「—」；**包含药品与耗材售卖**）；按日期（日/月/自定义区间）与按条目（药品+耗材，标注类型，可排序）两种视图；
  - **耗材使用**：汇总总使用量 + 按日期（日/月/自定义）+ 按耗材（可排序）；使用量 = Σ 操作明细数量；
  - 统计口径：销售额按销售记录中的售价快照计算；成本按统计时药品/耗材**当前进价**计算；未设置价格或已删除条目的历史记录不计入成本（其毛利显示「—」）。调整进价会影响历史毛利。

## 医疗耗材与操作

- **耗材管理**：「医疗」Tab →「耗材」：添加耗材（名称/单位/初始存量/阈值/进价/卖出价），创建后当前存量 = 初始存量；卡片「进货」按钮调整存量（设置新存量或增加量，增加量可为负数修正）；删除二次确认，历史销售/操作记录保留。
- **医疗操作**：「医疗」Tab →「医疗操作」：输入操作类型（常用建议：换药/清创/消毒/包扎…，可自定义）、勾选本次使用的耗材与数量（可多行）、备注，点**「确认记录」**后批量扣减耗材存量并写入操作记录（只增不改不删，明细保存耗材名称/单位快照）；操作历史按时间倒序，可按类型筛选。耗材扣减允许负数（与药品一致）。

## 有效期与临期/过期提醒

- 药品可设置「有效期至」（日期，可空，添加/编辑均可修改）；库存列表显示有效期，**临期（距到期 ≤ 90 天）显示橙色「临期」标记，已过期显示红色「已过期」标记**。
- **过期药品禁止销售**：手动登记下拉中显示「已过期」且不可选；OCR 确认列表中标记「已过期」并阻止该项扣减（提示先处理库存）。有效期以本地日期判断。

## 微信内置浏览器限制

微信内置浏览器**不支持 PWA 安装与离线**，且 OCR 联网加载可能受限。页面顶部会出现提示条，建议点击右上角「···」→「在浏览器打开」，用系统浏览器（Chrome / Safari）使用完整功能。手动登记、查看库存等核心功能在微信内可用。

## OCR 使用说明

- 首次点击「拍照识别/相册识别」时**联网**下载识别引擎与中文语言包（约 10MB+），页面显示加载进度；加载失败可重试（自动切换备用 CDN）或放弃。
- 识别结果以**可编辑确认列表**呈现：条目可改选（候选**同时包含药品与耗材**）、数量可改、行可删；未匹配行显示原始文本供手动补选。
- 只有点击**「确认扣减」**才写入数据（扣库存/存量 + 生成 OCR 来源记录）；「放弃」不写任何数据。
- 手写单据识别率不保证，可随时放弃 OCR 改用「手动登记」。

## 条码扫码使用说明

- **入口**：①「库存」→ 添加/编辑药品弹层中的「📷 扫码」按钮（扫到即自动填入条码字段）；②「登记销售」页「📷 扫码选药」按钮（扫到即匹配并选中库存中该条码的药品，可直接填数量确认扣减；未收录会提示先添加并录入条码；命中药品已过期会阻止并提示）。
- **实现**：浏览器优先使用原生 `BarcodeDetector`（Android Chrome 支持）；不支持时自动**联网懒加载**备用扫码库 html5-qrcode（CDN，类似 OCR 模式）。**APK 内不走网页摄像头**（WebView 不支持），自动切换为 **Capacitor 原生扫码插件**（`@capacitor/barcode-scanner`，系统摄像头全屏扫码，ZXing 本地解码、无需 Google Play 服务，国内手机可用）。扫码画面与码值**仅本地处理，不联网、不查外部药品库**（纯本地匹配自己库存中的条码字段）。
- **环境要求**：浏览器扫码依赖摄像头，需在 **HTTPS 或 localhost** 环境使用（浏览器安全限制），并授权摄像头权限；权限被拒绝或无摄像头时，弹层会提示改用「手动输入条码」。桌面 Chrome/Edge 在 HTTPS 站点下同样可扫码。**APK 内扫码无 HTTPS 限制**，首次使用会弹出系统相机权限申请，拒绝后同样可改用「手动输入条码」。
- 条码为可选字段，**一药一码**（重复条码会被拒绝）；二维码内容同样支持（统一按字符串存储）。

## 桌面安装引导（Windows）

应用满足 PWA 安装条件（HTTPS + manifest + 图标 + Service Worker），Chrome / Edge 可直接安装为桌面应用：

- **Chrome**：用 Chrome 打开线上网址 → 地址栏右侧出现「安装」图标（显示器＋下载箭头）→ 点击「安装」；或点右上角 ⋮ →「安装药品库存管理…」。
- **Edge**：用 Edge 打开线上网址 → 地址栏右侧「应用可用」图标（＋）→「安装」；或点右上角 ⋯ →「应用」→「将此站点安装为应用」。
- 安装后从**开始菜单/桌面快捷方式**打开，窗口 **≥768px 自动切换为宽屏布局**（内容区 960px、药品/耗材列表多列网格、表单弹层居中加宽），表单支持**回车提交**、按钮有悬停效果；断网也能打开使用。安装占用极小（约 165KB，OCR/扫码库按需 CDN 加载不占安装空间）。

## APK 安装（Android）

- **获取**：代码推送到 GitHub 仓库后，Actions 工作流（`.github/workflows/build-apk.yml`）自动用 Capacitor 把 `deploy-dist/` 打包为调试签名 APK；在仓库 Actions 页面打开最新一次「Build APK」运行记录，底部 **Artifacts** 下载 `drug-inventory-apk`（约 15~20MB）。
- **安装**：把 APK 传到手机（数据线/网盘/微信文件传输助手），点击安装——需允许「安装未知来源应用」（调试签名，个人使用足够）。
- **更新**：修改功能并推送后重新触发构建（`workflow_dispatch` 手动触发或 push 自动），下载新 APK 覆盖安装即可（APK 内 WebView 数据通常保留）。
- **数据迁移**：APK 内数据存于其 WebView 的 localStorage，**与网页版互相独立**。网页版 ↔ APK 之间用「导出备份 / 导入备份」迁移：网页版导出 JSON → 文件传到手机 → APK 内「⋮ → 导入备份」恢复（反之亦然）。
- **注意**：APK 内扫码走 **Capacitor 原生摄像头插件**（系统相机全屏扫码，ZXing 本地解码、不依赖 Google Play 服务；构建时已注入 CAMERA 权限，首次扫码会弹出系统权限申请）；OCR 在 APK 内也会自动申请相机权限。APK 为补充交付，网页版 PWA 仍是体积最小、自动更新的首选。

## 运行测试

需要 Node.js ≥ 18（内置 test runner）：

```bash
cd drug-inventory-app
node --test "tests/*.test.js"
```

或指定文件：

```bash
node --test tests/parser.test.js
node --test tests/storage.test.js
node --test tests/scanner.test.js
```

测试覆盖 `parser.js`（§3.5 解析规则）、`storage.js`（schema、药品/耗材 CRUD、销售（药品+耗材）、医疗操作、有效期、条码唯一性、导入导出版本校验、售价快照、加载归一化，localStorage 用 mock）、`scanner.js`（BarcodeDetector 可用性、码值归一化、条码匹配、CDN 降级加载、扫码会话）与 `stats.js`（销售额/成本/毛利/毛利率、按日期/按条目聚合、排序、耗材使用统计、分位精度）。

## 浏览器要求

现代移动/桌面浏览器：Chrome、Edge、Safari（iOS 15+ 对 PWA 支持较好）。Tesseract OCR 与扫码降级库（html5-qrcode）依赖网络加载 CDN，弱网环境下请耐心等待或重试。
